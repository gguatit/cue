# Cue 자유 모드 프롬프트 모음

화면에 보이는 문제나 내용을 Cue 자유 모드에서 확인할 때 붙여넣는 범용 프롬프트입니다. 특정 문제나 정답에 묶여 있지 않습니다.

## 사용 방법

1. Cue 앱에서 자유 모드를 켭니다.
2. 테스트 화면에 문제나 내용을 띄웁니다.
3. 아래 프롬프트 중 하나를 복사해 Cue 자유 모드에 붙여넣습니다.
4. 답변이나 설명을 확인합니다.

사이트는 AI를 직접 호출하지 않으며 API 키를 저장하지 않습니다.

## 답과 풀이

### 정답과 이유

화면에 보이는 문제의 정답을 먼저 말하고, 왜 그 답이 맞는지 단계별로 설명해줘.

### 단계별 풀이

화면에 보이는 문제를 처음부터 끝까지 단계별로 풀어줘. 중간 계산과 판단 근거를 빠뜨리지 마.

### 오답 비교

화면에 보이는 문제의 각 선택지가 왜 맞는지 또는 왜 틀린지 하나씩 비교해줘. 마지막에 정답을 정리해줘.

## 설명과 힌트

### 힌트만

화면에 보이는 문제의 정답은 말하지 말고, 스스로 풀 수 있도록 핵심 힌트만 3개 줘.

### 핵심 개념 3줄

화면에 보이는 문제를 풀기 위해 필요한 핵심 개념을 3줄로 정리해줘. 어려운 용어는 짧게 풀어서 설명해줘.

### 쉬운 설명

화면에 보이는 문제를 처음 배우는 사람도 이해할 수 있게 아주 쉽게 설명해줘. 마지막에 정답을 알려줘.

## 학습 정리

### 채점 기준

화면에 보이는 서술형 문제의 모범답안과 채점 기준을 알려줘. 꼭 들어가야 하는 핵심 포인트와 감점 요소를 구분해줘.

### 내 답안 검토

화면에 보이는 문제와 내가 작성한 답안을 비교해줘. 맞은 부분, 빠진 부분, 고칠 부분을 구분해서 알려줘.

## 정리와 변환

### 3줄 요약

화면에 보이는 내용을 핵심만 남겨 3줄로 요약해줘. 중요한 숫자나 조건은 빠뜨리지 마.

### 표로 정리

화면에 보이는 내용을 비교하기 쉬운 표로 정리해줘. 항목, 차이, 주의할 점이 드러나게 해줘.

### 한국어로 번역

화면에 보이는 영어 지문이나 설명을 자연스러운 한국어로 번역해줘. 전문 용어는 원어를 괄호에 함께 표시해줘.

## 코드

### 코드 실행 흐름

화면에 보이는 코드가 어떤 순서로 실행되는지, 입력과 출력이 어떻게 바뀌는지 단계별로 설명해줘.

### 오류와 개선점

화면에 보이는 코드에서 오류가 날 수 있는 부분과 개선할 점을 찾아줘. 가능하면 수정 예시도 보여줘.
