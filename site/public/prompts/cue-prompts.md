# Cue Test Lab — 프리셋 프롬프트

Cue 자유 모드나 다른 AI 도구에 붙여넣어 사용하는 프롬프트 모음입니다.  
사이트의 각 문제 카드에서는 문제 내용이 자동으로 채워진 프롬프트를 복사할 수 있습니다.

## 사용법

1. Cue Test Lab에서 문제를 엽니다.
2. 문제 카드 아래의 **프리셋 프롬프트**에서 원하는 항목을 고릅니다.
3. **프롬프트 복사**를 누릅니다.
4. Cue 자유 모드에 붙여넣고 실행합니다.
5. AI 답변은 항상 검증하고, 실제 시험·평가에는 사용하지 않습니다.

사이트는 AI를 직접 호출하지 않으며 API 키도 저장하지 않습니다.

## 공통 프리셋

### 1. 정답과 이유

```text
{{question}}

정답을 먼저 말하고, 왜 그 답이 맞는지 단계별로 설명해줘.
```

### 2. 오답 분석

```text
{{question}}

정답을 고른 뒤, 각 선택지가 왜 맞거나 틀린지 하나씩 비교해줘.
```

### 3. 힌트만

```text
{{question}}

정답은 말하지 말고, 스스로 풀 수 있도록 핵심 힌트만 3개 줘.
```

### 4. 핵심 개념 3줄

```text
{{question}}

이 문제를 풀기 위해 필요한 핵심 개념을 3줄로 정리해줘.
```

### 5. 쉬운 설명

```text
{{question}}

중학생도 이해할 수 있게 아주 쉽게 설명하고, 마지막에 정답을 알려줘.
```

### 6. 채점 기준

```text
{{question}}

서술형 답안을 채점한다면 필요한 핵심 포인트와 감점 요소를 표로 정리해줘.
```

### 7. 내 답 비교

```text
{{question}}

내 답안:
{{my_answer}}

내 답안과 모범답안을 비교하고, 빠진 내용과 고칠 점을 알려줘.
```

### 8. 오답 노트

```text
{{question}}

내가 고른 답/작성한 답:
{{my_answer}}

내 답이 왜 틀렸는지, 어떤 개념을 다시 봐야 하는지 오답 노트 형식으로 정리해줘.
```

## 유형별 추가 프롬프트

### 객관식

```text
{{question}}

정답 라벨과 선택지 내용을 함께 말하고, 다른 선택지가 틀린 이유를 한 줄씩 설명해줘.
```

### 서술형

```text
{{question}}

모범답안을 3~5문장으로 작성하고, 채점 기준을 [핵심 개념 / 근거 / 결론]으로 나눠줘.
```

### 코드형

```text
{{question}}

코드의 실행 흐름을 한 줄씩 설명하고, 시간 복잡도와 출력값을 알려줘.
```

### 계산형

```text
{{question}}

풀이 과정을 식으로 보여주고, 중간 계산과 최종 답을 분리해서 설명해줘.
```

## 주의

- AI 답변은 틀릴 수 있습니다. 반드시 교과서·강의·공식 자료로 검증하세요.
- 실제 시험·평가에서는 사용을 권장하지 않습니다.
- 프롬프트에 개인정보나 민감한 정보를 넣지 마세요.
