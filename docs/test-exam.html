테스트 방법
  1. Cue 설정 → 모드에서 원하는 표시 모드를 켭니다. LED 모드를 쓰려면 키보드 LED를 켜고 키를 고른 뒤 깜빡임 테스트로 하드웨어를 확인하세요.
  2. 이 페이지를 전체 화면(F11)으로 띄웁니다.
  3. 문제 번호 위에 마우스 포인터를 두고 Ctrl + Alt + Win을 누릅니다.
  4. 표시된 답을 확인합니다. LED 모드는 깜빡인 횟수가 답입니다.
