# Cue 아이디어와 결정

이 문서는 Cue의 **제품 원칙, 검토한 아이디어, 보류·제외한 결정**을 기록합니다. 같은 아이디어를 반복해서 제안하지 않기 위한 문서이며, 기능 제안 전에 [OUT_OF_SCOPE.md](OUT_OF_SCOPE.md)와 함께 읽습니다.

- 현재 버전: **0.5.5**
- 관련 문서: [README](../README.md), [ARCHITECTURE.md](ARCHITECTURE.md), [AI_HARNESS.md](AI_HARNESS.md)

## 1. 제품 원칙

| 원칙 | 질문 |
|---|---|
| 한 번의 동작 | 이 기능이 캡처→요청→표시 흐름을 더 짧게 만드는가? |
| 조용한 답 | 화면에 남는 흔적을 줄이는가? |
| 로컬 우선 | 서버·계정·텔레메트리 없이 동작하는가? |
| 공급자 독립 | 특정 AI 공급자에 종속되지 않는가? |
| 실패 시 안전 | 보호가 실패하면 표시하지 않는가? |
| 작은 표면적 | 새 의존성·설정·유지보수 비용이 정당한가? |
| 측정 가능 | 실제 사용자 문제를 줄이는가, 아니면 설정만 늘리는가? |

### 핵심 가치

Cue의 핵심은 **“문제를 복사하지 않고, 한 번의 조용한 답을 얻는다”**입니다. 이 가치를 직접 개선하지 않는 기능은 우선순위가 낮습니다.

## 2. 현재 초점

현재는 기능 확장보다 **정확성·안정성·성능·문서화**에 집중합니다.

- 캡처 보호와 오버레이 표시의 회귀 방지
- 공급자별 요청 형식·토큰 필드 호환성
- 스트리밍·교차 검증·대체 모델의 실패 경로
- 시작 시간과 메모리 사용량
- 릴리스·업데이트 무결성
- README·아키텍처·프롬프트 문서의 최신화

## 3. 최근 결정

| 버전 | 결정 | 이유 |
|---|---|---|
| 0.5.0 | 서술형 SSE 스트리밍 + 토큰 사용량 표시 | 긴 답변의 체감 지연을 줄이고 비용을 확인할 수 있게 함 |

| 0.5.2 | 창 드래그 중 150ms blur 유예 | Windows가 드래그 중 포커스를 잠시 잃을 때 창이 숨는 문제 수정 |

| 0.5.5 | 실험실 탭 + 커서 밀착 답변 | 검증 중인 UX를 기본 OFF로 분리하고, 실사용 후 정식 탭으로 이동 |

### 제외

| 아이디어 | 이유 |
|---|---|
| OCR 텍스트 모드 | 한글 OCR 정확도·언어팩·지연 위험이 크고 핵심 가치를 직접 개선하지 않음 |
| 한 화면 다중 문제 일괄 풀이 | 화면 체류 시간과 모호성이 커짐 |
| 후속 질문 (“왜 이 답인가?”) | 한 번의 조용한 답이라는 핵심 가치와 맞지 않음 |
| 직접 크롭 캡처 | 기존 1600×1000 크롭과 동일하고 기본 크롭이 꺼져 있어 이득이 제한적 |
| 로컬 진단/성능 로그 내보내기 | 일반 사용자가 쓰지 않음 |
| AI OG 이미지 생성 | 결과물 품질이 기준에 못 미침. 필요하면 HTML/CSS 카드 + 스크린샷 |
| 홍보 사이트 확장(영문·JSON-LD·사이트맵 등) | 현재 사이트 v1으로 충분 |
| CI 구축 | 수동 릴리스로 대체 |
| 테스트 품질 감사 | 별도 테스트 리팩터링은 사용자 요청 범위가 아님 |
| 크롭/프라이버시 기본값 변경 | 현재 기본값 유지 |
| 위치 미리보기 | 설정 항목만 늘리고 실제 이득이 작음 |
| 텍스트 크기 프리셋 | 기본 크기로 충분 |
| 표시 시간 프리셋 | 현재 슬라이더로 충분 |
| 스트리밍 속도 설정 | 자동 페이싱으로 충분 |
| 트레이에서 모델 전환 | 설정 창에서 바꾸는 흐름이 더 명확함 |

## 5. 다음 후보

우선순위는 **사용자 통증이 크고, 새 의존성 없이 검증 가능한 것**입니다.

1. **캡처 보호 회귀 테스트 강화**
   - Windows 업데이트 후 WDA affinity, 오버레이 표시, 회의 모드가 함께 깨지지 않는지 확인.
2. **공급자 호환성 표**
   - 모델별 API·토큰 필드·스트리밍 지원 여부를 문서와 테스트로 고정.
3. **다중 모니터 DPI 검증**
   - 100%/125%/150%/200% 혼합 환경에서 오버레이 위치·크기 확인.
4. **업데이트 사전 점검**
   - 디스크·네트워크·서명 오류를 설치 전에 더 친절하게 안내.
5. **문서 링크 검사**
   - README·docs의 상대 링크와 이미지 경로를 릴리스 전에 검사.
