# Out of scope

이 문서는 이미 검토 후 **명시적으로 제외한** 기능과 결정을 기록한다. 사용자가 방향을 바꾸지 않는 한 다시 제안하지 않는다. 기능 제안·계획 전에 이 파일을 먼저 읽는다.

## 0.2.0에서 제외

- **유료 Authenticode 코드 서명**: OV/EV 인증서, HSM/token 비용. 무료 SignPath Foundation OSS 서명도 아직 결정하지 않았다.
- **로컬 진단/성능 로그 내보내기**: 일반 사용자가 쓰지 않는다.
- **후속 질문**: 마지막 캡처로 “왜 이 답인가?”를 묻는 기능. 핵심 가치(한 번의 조용한 답)와 맞지 않는다.
- **한 화면 다중 문제 일괄 풀이**: 화면 체류 시간과 모호성이 커진다.
- **OCR 텍스트 모드**: 한글 OCR 정확도·언어팩·지연 위험이 크고 핵심 가치를 직접 개선하지 않는다.
- **직접 크롭 캡처**: 기존 1600×1000 크롭 영역과 동일하며, 기본 크롭이 꺼져 있어 이득이 제한적이다.
- **AI OG 이미지 생성**: 결과물 품질이 기준에 못 미쳐 중단했다. 필요하면 HTML/CSS 카드 + 스크린샷으로 만든다.
- **홍보 사이트 확장**: 영문 페이지, JSON-LD, 사이트맵, 모바일 섹션 메뉴, Cloudflare Web Analytics 등. 현재 사이트는 v1으로 충분하다.
- **CI 구축**: GitHub Actions 워크플로는 수동 릴리스로 대체했다.
- **테스트 품질 감사**: 별도 테스트 리팩터링은 사용자 요청 범위가 아니다.
- **크롭/프라이버시 기본값 변경**: 현재 기본값을 유지한다.

## 영구 제약

- 서버·계정·텔레메트리·분석 호출을 추가하지 않는다.
- API 키는 Windows 자격증명 관리자에만 저장하고 로그·설정 내보내기에 포함하지 않는다.
- 내장 프리셋의 공식 엔드포인트 고정과 `validate_base_url`을 느슨하게 하지 않는다.
- 오버레이·트레이는 항상 다크로 유지한다.
- 앱에 shadcn/ui를 추가하지 않는다(사이트만).
- 새 JavaScript 의존성을 추가하지 않는다.
- 네이티브 제목 표시줄을 유지한다.
- 제거 프로그램·보호·업데이트 서명·uninstaller 훅 동작을 깨지 않는다.

## 나중에 검토 가능 (0.2.x)

- 고DPI 모니터별 UI 스케일 보정
- 업데이트 설치 전 디스크/네트워크 사전 점검
- 무료 SignPath Foundation OSS 서명 (사용자가 결정할 때만)
