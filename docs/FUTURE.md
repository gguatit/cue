# Cue Future Work

Rune 하이브리드 전환에서 **아직 계획하지 않은** 항목을 모아두는 문서입니다.  
여기 있는 항목은 승인된 작업이 아니며, 별도 계획과 게이트 없이 구현하지 않습니다.

- 현재 앱: **0.3.2**
- 전환 설계: `docs/superpowers/specs/2026-11-10-rune-hybrid-adoption-design.md`
- 전체 계획: `docs/superpowers/plans/2026-11-10-rune-hybrid-adoption.md`
- Phase 0: `docs/superpowers/plans/2026-11-10-rune-overlay-poc.md`
- 제외 범위: `docs/OUT_OF_SCOPE.md`

## 상태

| 상태 | 의미 |
|---|---|
| 결정 필요 | 방향 자체를 아직 정하지 않음 |
| 선행 필요 | 이전 Phase 통과 후에만 계획 가능 |
| 후보 | 필요성이 있지만 일정·범위 미정 |
| 보류 | 사용자가 명시적으로 보류 |

## 1. Tauri 호스트 제거

| 항목 | 내용 | 상태 |
|---|---|---|
| 전체 Tauri 제거 | WebView뿐 아니라 트레이·업데이터·NSIS·single-instance까지 Rune/자체 구현으로 교체 | 결정 필요 |
| 트레이 이전 | Rune 또는 별도 Windows 셸이 트레이·메뉴·알림을 소유 | 결정 필요 |
| 자동 업데이터 교체 | Tauri updater를 자체 서명 업데이터로 교체 | 결정 필요 |
| NSIS/설치 훅 교체 | `windows/hooks.nsh`, perMachine, WebView2 오프라인 설치, 관리자 보호 복사본 | 결정 필요 |
| 단일 인스턴스 교체 | `tauri-plugin-single-instance` 대체 | 결정 필요 |

현재 계획의 종료 상태는 **Rune UI + Tauri 호스트 유지**입니다. 전체 호스트 제거는 Phase 6의 별도 프로젝트입니다.
