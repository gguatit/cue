## 0.2.0 — 2026-11-03

- 제외 범위와 영구 제약을 `docs/OUT_OF_SCOPE.md`에 정리하고, 기능 제안 전에 확인하도록 AGENTS에 명시했습니다.

- 설정 저장 형식 v20: `provider.fallbackModel` 추가. 테마(v19), 마우스 트리거(v17) 설정은 유지됩니다.
- 설정 셸·테마는 0.1.20/0.1.21의 native UI를 유지합니다. AI·보안·정보·사용법의 세부 행 마이그레이션은 다음 패스입니다.

- 업데이트 후 `%TEMP%`에 남는 설치 파일을 다음 실행 때 자동 정리합니다.

- 관리자 보호 복사본 갱신에 실패하면 업데이트를 막지 않고 보안 탭에 복구 경고를 표시합니다.
