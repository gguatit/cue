# 변경 기록

## 0.1.6 — 2026-10-27

개선
- 최대 보호(관리자 권한으로 실행)와 생존 보호 카드에 **설정됨 / 설정 안 됨** 상태 배지를 표시합니다. 관리자 모드가 켜져 있지만 아직 승격되지 않은 경우에는 재시작 필요로 표시합니다.

## 0.1.5 — 2026-10-27

추가
- 설정 → 정보에서 Windows 임시 폴더에 남은 이전 업데이트 설치 파일을 즉시 삭제할 수 있습니다.
- Windows Defender 예외 추가 전에 현재 추가 상태를 확인하고, 이미 추가된 경우 다시 눌러도 안전하다는 결과를 표시합니다.

개선
- 업데이트 설치 확인을 브라우저식 `window.confirm` 대신 앱 안의 전용 확인창으로 표시합니다.

## 0.1.4 — 2026-10-27

수정
- 업데이트 확인이 시스템 프록시의 오래된 캐시를 재사용해 실패하던 문제를 수정했습니다. 확인·다운로드 요청에 `Cache-Control`/`Pragma: no-cache` 헤더를 추가했습니다.
- `latest.json`을 UTF-8 BOM 없이 생성하도록 `scripts/latest-json.ps1`을 추가했습니다. BOM이 있으면 updater가 응답을 JSON으로 읽지 못합니다.
- 업데이트 응답 파싱 실패를 네트워크 오류와 구분해 표시합니다.

## 0.1.3 — 2026-10-27

수정
- 자동 업데이트 확인이 네트워크 오류로 실패해도 24시간 동안 다시 시도하지 못하던 문제를 수정했습니다. 이제 성공한 확인만 마지막 확인 시각으로 기록합니다.

## 0.1.2 — 2026-10-27

추가
- 설정 → 정보에서 GitHub Releases의 서명된 새 버전을 확인하고 설치할 수 있습니다. 자동 확인은 하루 한 번이며 끌 수 있습니다.
- 업데이트는 NSIS `/UPDATE`로 설치되어 기존 제거 프로그램의 서비스·예약 작업·ProgramData 정리를 그대로 유지합니다.
- 업데이트 후 `%TEMP%`에 남는 설치 파일을 다음 실행 때 자동 정리합니다.

보안·개선
- 관리자 보호 복사본 갱신에 실패하면 업데이트를 막지 않고 보안 탭에 복구 경고를 표시합니다.
- 업데이트 재시작 시 `--elevated` 인자를 실제 관리자 토큰으로 검증합니다.
- 트레이 툴팁을 중립화하고, 회의 감지·패닉 중에는 트레이와 오버레이를 숨깁니다. 회의 감지 대상 프로세스와 창 제목을 확장했습니다.
- 메인 창 제목을 중립화하고, 작업표시줄 숨김은 버튼만 숨기며 최소화·최대화·닫기 버튼은 그대로 유지합니다. 화면 캡처 보호 적용 상태를 보안 탭에 표시합니다.
- 0.1.0/0.1.1 사용자는 0.1.2를 한 번 직접 설치해야 이후 자동 업데이트가 동작합니다.

## 0.1.1 — 2026-10-25

수정
- 답변 단축키에 **마우스 클릭 필요** 옵션과 왼쪽/오른쪽/가운데 버튼 선택을 추가했습니다. 설정한 보조키를 누른 채 선택한 버튼을 클릭해야 발동하며, 키만 누르면 아무 일도 일어나지 않습니다.
- modifier-only 답변 단축키가 같은 보조키를 쓰는 패닉 단축키를 가리던 문제를 수정했습니다. 충돌하는 기존 설정은 클릭 필요 모드로 자동 전환됩니다.
- 앱 설정 화면과 README/AGENTS/도움말에 전역 단축키 충돌 가능성 경고를 추가했습니다.

## 0.1.0 — 2026-10-24

첫 공개 릴리스.

- Windows 10/11 x64용 시험 보조 데스크톱 앱.
- 전역 단축키로 커서가 있는 모니터를 캡처해 OpenAI 호환 비전 모델에 질문합니다.
- 트레이 아이콘 위장, 커서 오버레이, 화면 플래시, 키보드 LED, 화면 밝기로 답을 표시합니다.
- 서술형 답변, 답변 기록, Panic 초기화, 회의 안전 모드, 생존 보호, `CueWatchdog` 서비스를 포함합니다.
- API 키는 Windows 자격증명 관리자에만 저장합니다. 계정·구독·텔레메트리는 없습니다.
