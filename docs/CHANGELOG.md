# 변경 기록

## 0.6.1 — 2026-11-20

재실행
- 관리자 모드에서 Cue 창을 닫은 뒤 다시 실행해도 숨은 창이 올라오지 않던 문제를 고쳤습니다.
- 수동 UAC 재실행 인자에서 `--background`를 제거해, 재실행이 백그라운드 인스턴스로 시작되지 않게 했습니다.
- `--admin-check`를 elevated 실행으로 인식하도록 정리하고 회귀 테스트를 추가했습니다.

## 0.6.0 — 2026-11-19

실험실 정리
- `커서 밀착 답변`을 실험실에서 **모드 → 서술형 답변 위치 → 커서 옆**으로 승격했습니다. 모드 탭에서 미리보기와 함께 사용할 수 있습니다.
- `스포트라이트 답변`, `캡처 미리보기`, `커서 정지 자동 답변`을 제거했습니다. 설정·오버레이·캡처·입력 훅의 관련 경로도 함께 정리했습니다.
- 실험실에는 `정지 시 미리 캡처`와 `정답 위치 하이라이트`만 남겼습니다. 둘 다 기본 OFF와 경고를 유지합니다.
- 기존 설정에서 `커서 밀착 답변`을 켜 두었다면 `서술형 답변 위치=커서 옆`으로 자동 이전됩니다.
- 설정 버전을 27로 올렸습니다.

## 0.5.10 — 2026-11-19

서술형 답변 크기
- 1px 테두리를 크기 계산에 포함해 짧은 답변에서 하단 글자가 잘리지 않게 보정했습니다.
- 0.5.9의 자동 크기 조절과 스트리밍 리사이즈는 그대로 유지합니다.

## 0.5.9 — 2026-11-19

서술형 답변 크기
- 답변 글자 수와 줄 수에 맞춰 오버레이 창이 작게 시작해 필요한 만큼 자동으로 커집니다.
- 짧은 답변은 260×86부터 시작하고, 일반 텍스트는 모니터의 70%, 커서 밀착 답변은 50% 높이까지 커집니다. 넘치는 긴 답변은 패널 안에서 스크롤됩니다.
- 스트리밍 중에는 80ms 단위로 실제 누적 텍스트에 맞춰 창 크기와 위치를 다시 계산합니다.
- 캡처 미리보기 썸네일이 있으면 썸네일 높이를 포함하고, 다중 모니터 DPI와 작업 영역 경계도 유지합니다.

## 0.5.8 — 2026-11-19

트레이
- Program Files 설치에서 Windows가 트레이 경로를 `{6D809377-6AF0-444B-8957-A3773F02200E}\Cue\cue.exe` 같은 known-folder GUID 경로로 저장해, Cue가 자기 트레이 항목을 찾지 못하고 숨김 영역에 남던 문제를 고쳤습니다.
- Windows 트레이 경로를 실제 `Program Files` 경로로 정규화해 기존에 표시되던 Cue 아이콘의 `IsPromoted`를 새 실행 파일에도 복사합니다.
- 업데이트 후 트레이 아이콘이 숨김 영역에 들어간 경우 0.5.8 첫 실행에서 한 번 표시 상태로 승격합니다. 사용자가 직접 숨긴 경우에는 다시 강제하지 않습니다.

## 0.5.7 — 2026-11-19

관리자 보호 복사본
- `Program Files`에 0.5.6 이상이 설치돼 있어도 `C:\ProgramData\Cue\cue.exe` 보호 복사본이 이전 버전으로 남아 관리자 모드·자동 시작이 옛 빌드를 실행하던 문제를 고쳤습니다.
- 설치 프로그램의 `--admin-prepare`가 Program Files의 새 exe를 ProgramData 보호 복사본으로 갱신하고, 예약 작업·서비스도 새 복사본을 사용하도록 다시 등록합니다.
- 0.5.5에서 0.5.6으로 올린 뒤 실험실 5종이 보이지 않던 환경은 0.5.7 설치 후 관리자 모드까지 새 빌드로 통일됩니다.
- 실험 기능과 설정 버전 26은 0.5.6과 동일합니다.

## 0.5.6 — 2026-11-19

실험실 기능 5종
- **스포트라이트 답변**: 전체 화면을 어둡게 덮고 커서 주변만 밝게 남겨 답변 카드를 표시합니다. 객관식 배지와 서술형 카드 모두 지원하며, 캡처 보호 fail-closed와 클릭 통과는 유지합니다.
- **캡처 미리보기**: 실제로 캡처한 문제 영역의 320px 썸네일을 서술형 답변 카드에 붙입니다. 스트리밍 답변에도 첫 페이로드부터 표시됩니다.
- **커서 정지 자동 답변**: 포인터가 약 700ms 멈추면 기존 답변 트리거를 자동 실행합니다. 이동 전에는 반복 발동하지 않고, 발동 후에는 포인터를 움직여야 다시 작동합니다. 기본 OFF입니다.
- **정지 시 미리 캡처**: 포인터가 약 400ms 멈추면 원본 화면만 로컬에 미리 캡처합니다. AI 요청은 답변을 실행할 때만 보내며, 2.5초·24px 이내의 캐시만 재사용합니다.
- **정답 위치 하이라이트**: 모델이 선택적으로 반환한 정답 선택지 좌표를 전체 화면 박스로 표시합니다. 좌표가 없거나 형식이 잘못되면 아무것도 그리지 않습니다. 모델별 지원 차이가 있습니다.
- 실험실의 경고·마스터 스위치·미리보기·경고 끄기 동작은 유지합니다. 설정 버전 26, 기존 설정과 기본 답변 위치는 유지됩니다.
- 검증: `npm run check`, `npm test`(227), `cargo test`(174), 서명 빌드.

## 0.5.0 — 2026-11-17

서술형 스트리밍
- 서술형·자유 모드 답변을 SSE로 받아 오버레이에 실시간 표시합니다. 객관식과 교차 검증은 기존처럼 전체 응답을 파싱합니다.
- Rust가 80ms 간격으로 누적 텍스트를 보내고, 오버레이는 `requestAnimationFrame`으로 45자/초에서 시작해 백로그에 따라 최대 500자/초까지 부드럽게 따라갑니다. 문장부호에서 짧게 쉬고, 마지막 조각은 약 0.6초 안에 마무리합니다.
- 스트리밍이 실패하면 같은 요청 안에서 비스트리밍으로 한 번 대체합니다. 둘 다 실패하면 오버레이를 숨깁니다.
- `prefers-reduced-motion`에서는 즉시 전체 텍스트를 표시합니다. 설정 → AI의 `서술형 스트리밍` 토글로 끌 수 있습니다.

토큰 사용량
- OpenAI Chat·Responses, Anthropic Messages, Google 네이티브, OpenCode 경로의 입력·출력·합계 토큰을 수집합니다. 재시도·보정·패러프레이즈·교차 검증 사용량을 합산합니다.
- 마지막 요청 카드와 답변 기록에 표시하며, 공급자가 보고하지 않으면 `—`로 표시합니다. `토큰 사용량 표시` 토글로 끌 수 있습니다.
- `extraJson`에서 `stream`과 `stream_options`를 덮어쓸 수 없습니다.

시작 성능
- 초기 JS 번들에서 `react-dom/server`와 `motion`을 제거했습니다. 트레이 아이콘은 정적 SVG로 그리고, 모션은 설정·오버레이 청크에서만 로드합니다. 초기 스크립트는 약 620KB에서 282KB로 줄었습니다.
- 관리자 보호 복구, 업데이트 확인, 회의 감지 첫 폴링을 창 표시 뒤로 미뤘습니다. 관리자 모드에서는 10초마다 `sc query`를 호출하지 않고, 예약 작업 유지보수 주기를 1분에서 5분으로 늘렸습니다.
- 시작 화면에 가벼운 스켈레톤을 표시해 흰 화면이 보이는 시간을 줄였습니다.

설정
- 설정 버전 23. `provider.streaming`, `answer.showUsage` 기본값은 켜짐입니다.

## 0.1.4 — 2026-10-27

수정
- 업데이트 확인이 시스템 프록시의 오래된 캐시를 재사용해 실패하던 문제를 수정했습니다. 확인·다운로드 요청에 `Cache-Control`/`Pragma: no-cache` 헤더를 추가했습니다.
- `latest.json`을 UTF-8 BOM 없이 생성하도록 `scripts/latest-json.ps1`을 추가했습니다. BOM이 있으면 updater가 응답을 JSON으로 읽지 못합니다.
- 업데이트 응답 파싱 실패를 네트워크 오류와 구분해 표시합니다.

## 0.1.2 — 2026-10-27

추가
- 설정 → 정보에서 GitHub Releases의 서명된 새 버전을 확인하고 설치할 수 있습니다. 자동 확인은 하루 한 번이며 끌 수 있습니다.
- 업데이트는 NSIS `/UPDATE`로 설치되어 기존 제거 프로그램의 서비스·예약 작업·ProgramData 정리를 그대로 유지합니다.
- 업데이트 후 `%TEMP%`에 남는 설치 파일을 다음 실행 때 자동 정리합니다.

보안·개선
- 관리자 보호 복사본 갱신에 실패하면 업데이트를 막지 않고 보안 탭에 복구 경고를 표시합니다.
- 업데이트 재시작 시 `--elevated` 인자를 실제 관리자 토큰으로 검증합니다.
- 트레이 툴팁을 중립화하고, 회의 감지·패닉 중에는 트레이와 오버레이를 숨깁니다. 회의 감지 대상 프로세스와 창 제목을 확장했습니다.
- 메인 창 제목을 중립화하고, 작업표시줄 숨김은 버튼만 숨기며 최소화·최대화·닫기 버튼은 그대로 유지합니다. 화면 캡처 보호 적용 상태를 보안 탭에 표시합니다.
- 0.1.0/0.1.1 사용자는 0.1.2를 한 번 직접 설치해야 이후 자동 업데이트가 동작합니다.

## 0.1.1 — 2026-10-25

수정
- 답변 단축키에 **마우스 클릭 필요** 옵션과 왼쪽/오른쪽/가운데 버튼 선택을 추가했습니다. 설정한 보조키를 누른 채 선택한 버튼을 클릭해야 발동하며, 키만 누르면 아무 일도 일어나지 않습니다.

- 앱 설정 화면과 README/AGENTS/도움말에 전역 단축키 충돌 가능성 경고를 추가했습니다.
