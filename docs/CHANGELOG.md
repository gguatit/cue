# 변경 기록

## 0.1.0 — 2026-10-24

첫 공개 릴리스.

- Windows 10/11 x64용 시험 보조 데스크톱 앱.
- 전역 단축키로 커서가 있는 모니터를 캡처해 OpenAI 호환 비전 모델에 질문합니다.
- 트레이 아이콘 위장, 커서 오버레이, 화면 플래시, 키보드 LED, 화면 밝기로 답을 표시합니다.
- 서술형 답변, 답변 기록, Panic 초기화, 회의 안전 모드, 생존 보호, `CueWatchdog` 서비스를 포함합니다.
- API 키는 Windows 자격증명 관리자에만 저장합니다. 계정·구독·텔레메트리는 없습니다.
